# What is Generative AI?

## 1. Definition

Generative AI (Generative Artificial Intelligence) is a branch of Artificial Intelligence that focuses on creating new content using models trained on existing data.

It can generate:

- Text
- Images
- Audio
- Video
- Computer Code
- Synthetic Data

Generative AI learns patterns, structures, and relationships from training data and uses them to produce new outputs.

## 2. How Does Generative AI Work?

Generative AI systems learn from large amounts of data during the training process.

After training, the model can generate new content based on user instructions or prompts.

### Basic Workflow

```text
        Training Data
              |
              v
       Data Processing
              |
              v
        Model Training
              |
              v
       Trained AI Model
              |
              v
       User Input / Prompt
              |
              v
          Inference
              |
              v
       Generated Output
```

## 3. Important Components

### A. Training Data

Training data is the information used to train an AI model.

Examples:
- Books
- Articles
- Images
- Audio recordings
- Programming code
- Videos

### B. Model

A model is a mathematical system that learns patterns and relationships from training data.

Examples:
- GPT
- Gemini
- Claude
- Llama

### C. Prompt

A prompt is an instruction or input provided to a generative AI model.

Example:

```text
Explain Machine Learning in simple words.
```

### D. Inference

Inference is the process of using a trained model to generate an output for a given input.

## 4. Major Types of Generative Models

### 1. Large Language Models (LLMs)

LLMs are trained to understand and generate human language.

Applications:
- Chatbots
- Text summarization
- Translation
- Question answering
- Code generation

Examples:
- GPT
- Gemini
- Claude
- Llama

### 2. Diffusion Models

Diffusion models generate content by learning to reverse a process that gradually adds noise to data.

They are widely used for image generation.

Examples:
- Stable Diffusion
- Imagen

### 3. Generative Adversarial Networks (GANs)

GANs consist of two neural networks:

- Generator: Creates synthetic data.
- Discriminator: Attempts to distinguish generated data from real data.

Both networks compete during training.

### 4. Variational Autoencoders (VAEs)

VAEs learn a compressed probabilistic representation of data and use it to generate new samples.

### 5. Autoregressive Models

Autoregressive models generate output one element at a time based on previously generated elements.

Many language models use this approach.

## 5. Generative AI vs Discriminative AI

| Generative Models | Discriminative Models |
|---|---|
| Learn how data is distributed | Learn relationships between inputs and labels |
| Generate new samples | Predict labels or values |
| Create new content | Classify or predict |
| Example: Text generation | Example: Spam detection |

## 6. Example of Generative AI

Input Prompt:

```text
Write a short paragraph about Artificial Intelligence.
```

Possible Output:

```text
Artificial Intelligence is a branch of computer science
that enables machines to perform tasks that typically
require human intelligence.
```

The model generates the response based on patterns learned during training.

## 7. Advantages

- Automates repetitive tasks.
- Improves productivity.
- Supports creative work.
- Generates content quickly.
- Helps developers write and understand code.
- Enables intelligent conversational applications.

## 8. Limitations

- Can generate incorrect information.
- May produce hallucinations.
- Can reflect biases in training data.
- Requires computational resources.
- May expose sensitive information if poorly designed.
- Output quality depends on model capabilities and input quality.
