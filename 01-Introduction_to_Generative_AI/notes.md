# 01 - Introduction to Generative AI

## 1. Introduction

Generative AI is a branch of Artificial Intelligence that focuses on generating new content such as text, images, audio, video, and code.

Unlike traditional AI systems that mainly analyze existing data or make predictions, Generative AI models learn patterns from training data and use those patterns to generate new outputs.

## 2. What is Artificial Intelligence?

Artificial Intelligence (AI) is a field of computer science that focuses on creating machines capable of performing tasks that typically require human intelligence.

Examples:
- Understanding natural language.
- Recognizing images.
- Making decisions.
- Solving problems.
- Learning from data.

## 3. Types of AI

### Based on capabilities

1. Narrow AI (ANI)
   - Designed for specific tasks.
   - Example: Face recognition, recommendation systems.

2. General AI (AGI)
   - A theoretical form of AI capable of performing a wide range of intellectual tasks at a human-like level.

3. Super AI (ASI)
   - A hypothetical form of AI that would surpass human intelligence across many domains.

### Based on functionality

1. Reactive Machines
2. Limited Memory
3. Theory of Mind
4. Self-Aware AI

Note: The last two are theoretical concepts, not established mainstream AI capabilities.

## 4. Types of Machine Learning

Machine Learning is a subset of Artificial Intelligence.

Main categories:

- Supervised Learning
- Unsupervised Learning
- Semi-Supervised Learning
- Reinforcement Learning

## 5. Traditional AI vs Generative AI

| Traditional AI | Generative AI |
|---|---|
| Analyzes existing data | Generates new content |
| Often performs classification or prediction | Generates text, images, audio, etc. |
| Usually task-specific | Can support multiple tasks |
| Example: Spam detection | Example: AI text generation |

## 6. What is Generative AI?

Generative AI uses models trained on large datasets to generate new content based on learned patterns.

Examples:
- ChatGPT generates text.
- Image generation models create images.
- Music generation models create audio.
- Code generation models generate programming code.

## 7. Important Terms

| Term | Meaning |
|---|---|
| AI | Artificial Intelligence |
| ML | Machine Learning |
| DL | Deep Learning |
| GenAI | Generative Artificial Intelligence |
| LLM | Large Language Model |
| NLP | Natural Language Processing |
| Prompt | Input or instruction given to an AI model |
| Token | Unit of text processed by a language model |
| Inference | Using a trained model to generate predictions or outputs |
| Training | Process of learning patterns from data |

## 8. Relationship Between AI, ML, DL and GenAI

- AI is the broader field.
- ML is a subset of AI.
- DL is a subset of ML.
- Generative AI is an approach that uses generative models and can be built using deep learning techniques.

## 10. Key Takeaways

- LLMs are an important part of Generative AI.
